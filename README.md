# CGPA-IQ-Package-Prediction

A Machine Learning web application that predicts a student's expected placement package based on their **CGPA and IQ score**.

The project uses **Multiple Linear Regression** to make predictions, with **Flask** as the backend and **HTML/CSS** for the user interface.

## 🚀 Features

* Predict expected placement package using CGPA and IQ
* Multiple Linear Regression model
* Flask backend
* Simple web-based user interface
* Real-time package prediction
* Trained ML model integrated with a web application

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Flask
* HTML
* CSS
* Pickle

## 🧠 Machine Learning Model

This project uses **Multiple Linear Regression** because the prediction is based on two independent variables:

* CGPA
* IQ

The model learns the relationship between these inputs and the expected placement package.

The trained model is saved as a `.pkl` file using Python's Pickle library and is loaded into the Flask application for making predictions.

## ⚙️ How It Works

1. The student enters their CGPA.
2. The student enters their IQ score.
3. Flask receives the input from the HTML form.
4. The trained Multiple Linear Regression model processes the inputs.
5. The model predicts the expected placement package.
6. The predicted package is displayed on the webpage.

## 📌 Input

* CGPA

## 📤 Output

* Predicted Expected Package in LPA
